## Scope and observed behavior

- `unios_staging` is a `no_std` checked ELF segment stager: it rejects invalid lengths
  and offsets **before modifying destination**, fills every byte of the destination
  page span with zero, copies only `p_filesz` bytes, then verifies file data,
  BSS and both leading/trailing slack.
- The pinned QEMU/OVMF loader reserves image and L1 boot frames through
  `AllocatePages`, acquires and validates a variable-stride UEFI map, probes
  *the current firmware CR3* for candidate identity-mapped writable pages,
  and copies all ELF PT_LOAD bytes into those reserved frames. It reads them
  back to check byte-for-byte integrity and zeroed BSS.
- The real freestanding kernel ELF now includes a retained 4 KiB zero-initialized
  `.bss.l1_probe` symbol, so the test does **not** rely only on fabricated
  host BSS fixtures. The future Rust entry checks first/last bytes if called.
- A dedicated `isa-debug-exit` write of 0x23 yields observed QEMU process code
  **71**, an E2b-only staged-copy result. No full L1 success token (0x20/65),
  no `HALTED_PASS`, no `ExitBootServices`, no kernel entry.

## Unresolved P0 and limits

The initial firmware page-table root read uses a provisional QEMU-only
**physical-address-as-linear-address probe**. Every later allocated page is
validated against the *current* old CR3 and must be identity-mapped and
writable, but **the very first root-table dereference is not independently
proven by the guest**. A memory fault or QEMU reset is a host FAIL; the
observed successful E2b run is **not** a general secure-mapping guarantee.
Before trusting a full CR3 cut, require independent/host-corroborated root
provenance and a post-ExitBootServices recheck (FA-02 / LC-O02).

The 512 KiB private page-table *allocation* is **not** page-table
construction. The stacks are reserved but not guarded/mapped for kernel
entry. Emergency GDT/IDT/TSS/#DF IST remain uninitialized. The final memory
map key is **not** suitable for ExitBS after diagnostics. There is no retry
state machine, no page-rights switch, no high-half execution, no system
calls or L2 features.

**Gate reading:** E0 partial, E1 artifact + staged-copy evidence partial,
E2a and E2b pre-exit portions observed, **E2 overall PARTIAL**;
E3/E4/E5 not validated. The 59 applicable L1 matrix IDs are not magically
satisfied by the unit/VM smoke tests; one DevSigned-only ID remains deferred.
